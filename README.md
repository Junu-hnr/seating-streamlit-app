# 자리배치 Streamlit 앱

## 1. 프로젝트 개요
Streamlit을 활용한 인터랙티브 자리 배치 애플리케이션입니다. 이 앱은 학생들의 좌석 배치를 효율적으로 관리하고, 사용자 친화적인 인터페이스를 제공합니다.

## 2. 주요 기능
- 학생 명단 관리 (저장/불러오기)
- 인터랙티브 좌석 설정 (비활성화, 사전 지정)
- 자동 자리 배치 (랜덤, 자리 띄우기)
- 엑셀 파일 내보내기

## 3. 실행 방법
1. 필요한 패키지를 설치합니다.
   ```bash
   pip install -r requirements.txt
   ```
2. Streamlit 앱을 실행합니다.
   ```bash
   streamlit run app.py
   ```

## 4. 파일 구조
- `app.py`: Streamlit 애플리케이션의 메인 진입점입니다.
- `specification.md`: 자리배치 앱 개발을 위한 상세 명세서입니다.
- `requirements.txt`: 프로젝트에 필요한 의존성 목록입니다.
- `README.md`: 프로젝트 개요 및 실행 방법을 설명합니다.
- `utils/`: 데이터 관리 및 자리 배치 알고리즘을 포함하는 유틸리티 모듈입니다.
- `tests/`: 자리 배치 알고리즘의 단위 테스트를 포함합니다.
- `.gitignore`: Git에서 무시할 파일 및 디렉토리 목록입니다.
